# Security Toolkit

Curated collection of security scripts, one-liners, and utilities for reconnaissance and hardening.

## Contents

- `recon/` — Subdomain enumeration, port scanning, asset discovery
- `hardening/` — Server hardening scripts and checklists
- `osint/` — OSINT automation and data collection
- `utils/` — General security utilities

## Usage

Scripts are organized by category. Each script includes a header with usage instructions.

```bash
# Example: subdomain enumeration
python3 recon/subdomain_enum.py -d example.com
```

## Disclaimer

These tools are for **authorized security research and defensive purposes only**. Always obtain proper authorization before testing any system you do not own.
